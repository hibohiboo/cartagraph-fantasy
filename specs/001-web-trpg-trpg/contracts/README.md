# WASM Interface Contracts

このディレクトリには、WebAssembly FFIインターフェースの契約定義が含まれています。

## ファイル構成

### `wasm-interface-task16.yaml`
**タスク16で実装する範囲** - MVPに必要な基本機能のみ

- 基本的なセッション管理（作成・プレイヤー追加）
- カード使用・ダイス振りの基本機能
- JSON形式でのシンプルな状態取得
- 既存のTask 7コントラクトテストが通る最小実装

**実装期間**: 4時間（タスク16）
**対象関数**: 7個の基本WASM関数
**複雑度**: シンプルな文字列ベースAPIと基本JSON serialization

### `wasm-interface-future.yaml`
**将来実装する完全版** - 本格的なTRPGゲームエンジン

- 包括的なイベントシステム
- 高度なルールエンジン統合
- パフォーマンス最適化された大容量データ構造
- リアルタイム状態同期
- スナップショット/復元機能
- 複雑な条件判定・効果解決

**実装期間**: 12-16時間（将来のタスク）
**対象関数**: 20+個の高度なWASM関数
**複雑度**: 型安全な複雑オブジェクト、ストリーミング、最適化

## 実装方針

1. **Task 16**: `wasm-interface-task16.yaml`に基づく最小実装
   - 既存コントラクトテストを通す
   - 基本的なゲーム機能の提供
   - TypeScript統合の確立

2. **将来タスク**: `wasm-interface-future.yaml`に基づく完全実装
   - 高度なゲームメカニクス
   - パフォーマンス最適化
   - 本格的なTRPGエンジン機能
